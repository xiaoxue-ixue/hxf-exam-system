# 接口文档：用户登录

> 第 4 周（上午）· 软件工程综合实践 产出物
> 可用 Apifox / Postman 录入，本文件为离线存档

## 通用约定

- 除登录外，所有接口需在请求头携带 `Authorization: Bearer <token>`
- 响应统一为 `{code, message, data}`，`code == 200` 表示成功

## 接口：用户登录

| 项 | 内容 |
|---|---|
| 接口名 | 用户登录 |
| 方法 | POST |
| 路径 | /auth/login |
| 说明 | 校验账号密码，成功返回 JWT 与用户信息 |

### 请求参数

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| username | string | 是 | admin | 账号 |
| password | string | 是 | 123456 | 密码 |

请求体（JSON）：

```json
{
  "username": "admin",
  "password": "123456"
}
```

### 响应示例

成功（code == 200）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOi...",
    "userId": 1,
    "username": "admin",
    "realName": "系统管理员",
    "role": "ADMIN"
  }
}
```

失败（账号或密码错误）：

```json
{
  "code": 500,
  "message": "账号或密码错误",
  "data": null
}
```
