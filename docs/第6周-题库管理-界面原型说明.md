## 一、分类管理页（CategoryList.vue）

### 1.1 线框示意

┌──────────────────────────────────────────────────────────────────────────┐
│ [新增分类]                                                                │
├──────────────────────────────────────────────────────────────────────────┤
│ ▾ 计算机网络                    [新增子分类] [编辑] [删除]                  │
│   ▾ 网络体系结构                [新增子分类] [编辑] [删除]                  │
│       OSI 七层模型              [新增子分类] [编辑] [删除]                  │
│       TCP/IP 四层模型           [新增子分类] [编辑] [删除]                  │
│   ▾ 网络层                      [新增子分类] [编辑] [删除]                  │
│       IP 地址与子网划分          [新增子分类] [编辑] [删除]                  │
│ ▾ 数据结构                      [新增子分类] [编辑] [删除]                  │
│   ▸ 线性表                      [新增子分类] [编辑] [删除]                  │
└──────────────────────────────────────────────────────────────────────────┘

### 1.2 区块与控件

| 区块 | 控件 | 说明 |
|---|---|---|
| 工具栏 | 「新增分类」按钮 | 新建顶级分类，parentId 固定传 0 |
| 树区域 | el-tree | 数据源是后端返回的嵌套结构，支持任意层级 |
| 行内操作 | 「新增子分类」 | 父分类自动带出当前节点 |
| 行内操作 | 「编辑」 | 回填名称、上级分类、排序 |
| 行内操作 | 「删除」 | 二次确认；有子分类或有题目时被后端拒绝 |
| 空态 | 文本「暂无分类数据」 | 通过 empty-text 设置，避免误以为加载失败 |

### 1.3 新增 / 编辑对话框（宽 400px）

| 字段 | 控件 | 约束 |
|---|---|---|
| 分类名称 | el-input | 必填，提交前 trim()，不能全空格 |
| 上级分类 | el-tree-select | 可清空；清空（null）提交时归一为 0；编辑时排除自己及后代 |
| 排序 | el-input-number | 最小值 0；同级按升序显示 |

### 1.4 交互要点

1. 顶部「新增分类」显式传 null，节点上的「新增子分类」传当前节点对象，一个函数处理两种情况
2. 树配置 :expand-on-click-node="false"，点节点文字不折叠，只有左侧箭头能展开
3. 三个行内按钮全部加 @click.stop，防止点击按钮时改变节点选中态
4. 上级分类下拉框用 check-strictly，允许选中任意层级（否则父子联动，单选场景行为异常）

## 二、题目管理页（QuestionList.vue）

### 2.1 线框示意

┌──────────────────────────────────────────────────────────────────────────┐
│ 题型[全部▾] 分类[全部▾] 难度[全部▾] 关键字[______] [搜索] [重置]            │
├──────────────────────────────────────────────────────────────────────────┤
│ [新增题目]                                                                │
│ ID │ 题型   │ 分类   │ 题干                 │ 难度 │ 分值 │ 创建人 │ 操作  │
│ 5  │ 简答题 │ 顺序表 │ 简述顺序表和链表的区别│ 困难 │ 10  │ 管理员 │ 预览… │
│                                       共 5 条  [10条/页▾]  < 1 >          │
└──────────────────────────────────────────────────────────────────────────┘

### 2.2 区块与控件

| 区块 | 控件 | 说明 |
|---|---|---|
| 筛选栏 | 题型 el-select | 选项值用字符串枚举（SINGLE/MULTI…），与后端 DTO 的 String 对应 |
| 筛选栏 | 分类 el-cascader | checkStrictly + emitPath: false，只取选中节点 id，允许选中间层 |
| 筛选栏 | 难度 el-select | 选项值是整数 1/2/3，与后端 Integer 对应 |
| 筛选栏 | 关键字 el-input | 回车即搜索；实际搜的是数据库 content 字段 |
| 工具栏 | 「新增题目」按钮 | 打开题型联动的空表单 |
| 表格 | 8 列 | ID、题型（标签）、分类、题干（超长省略+悬浮提示）、难度（标签）、分值、创建人、操作 |
| 分页 | el-pagination | v-model:current-page + v-model:page-size + @change |
| 行内操作 | 预览 / 编辑 / 删除 | 预览只读弹窗；编辑复用同一对话框；删除二次确认 |

### 2.3 新增 / 编辑对话框（宽 680px，top: 5vh）

公共字段：题型、分类、题干、解析、难度、分值。

| 题型 | 联动区域 |
|---|---|
| 单选题 SINGLE | 选项区（A~D 可编辑）+ 单选答案区（只列已填内容的选项） |
| 多选题 MULTI | 选项区 + 多选答案区（checkbox） |
| 判断题 JUDGE | 无选项区；答案区为「对 / 错」单选，值为 A / B |
| 填空题 FILL | 无选项区；答案区为「空 1 / 空 2 …」可增减，至少保留一个 |
| 简答题 SHORT | 无选项区；答案区为多行文本域 |

编辑态下题型下拉框 disabled：改题型会让 options 与 answer 的语义失效，属于刻意限制。

### 2.4 预览弹窗（宽 560px）

- 顶部 el-descriptions：题型、分值、难度、分类
- 题干、选项逐行列出
- 答案按题型翻译：判断题 → 对/错，多选题 → 顿号连接（A、B），其余原样
- 有解析时才显示解析区

## 三、与教程原型的差异说明

| 项 | 教程 | 本项目 | 原因 |
|---|---|---|---|
| 分类层级 | 两级 | 三级 | 数据结构更丰富，buildTree 递归天然支持 |
| 操作列 | 普通按钮 | 文字链接按钮 | 三个按钮在 190px 内换行，链接样式更紧凑 |
| 布局文件名 | Home.vue | Layout.vue | 语义更准确，第 5 周已定型 |
